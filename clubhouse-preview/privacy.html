No account is required to read, watch, or play.

Progress stays on this device

The new games save progress in this browser. Clearing website data removes it. The preview uses its own storage keys, separate from the live site's game progress.

Measurement in this preview

No visitor analytics service is connected. The review page has an optional test recorder that keeps events only in this browser. It does not report other visitors, identify people, count purchases, or send data to a server.

A future production analytics setup can measure page visits, outbound links, and active time. An Amazon link click is not proof of a purchase. There is no public visitor counter in this preview.

Outside services

A YouTube player loads only when you press play, using its privacy-enhanced embed domain. YouTube and Amazon apply their own policies when you interact with them. Links to those services open separately.

Accessibility

The new pages support keyboard navigation, visible focus, reduced motion, and browser zoom. Sound is optional. Daisy's chapter and Lost & Found have no timers, include text equivalents, and can be played with buttons instead of gestures. Bonus chapter text can be enlarged.

The existing games are still being improved. Real phone and foldable testing is part of review before production. Podcast transcripts remain to be added; no transcript has been invented.
